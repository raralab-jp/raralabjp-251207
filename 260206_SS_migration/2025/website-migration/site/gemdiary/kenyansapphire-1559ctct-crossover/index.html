夜空を横断する流星群。そんな印象を抱かせるケニア産サファイアです。

イタリア人研磨師Ramon Tesoroにカットしてもらったケニア産のサファイア。

「テーブルがずいぶんと広いなあ！？」
それが、このルースを見た第一印象でした。

ルースをしばらく眺めていると、テーブルを斜めに横切るインクルージョンが目に入ります。
まるで、流星群が夜空を横断しているよう。

Ramonがテーブルを広くとったのは、この煌めきを見せてくれるためだったのかも、と思いました。

Ramonにカットしてもらったケニア産サファイアは、ほかにもインクルージョンが楽しめるものがありますが、輝き方はこのルースがいちばんはっきりしています。

後ろから見ると中央付近に黄色のカラーバンドがあります。この黄色は正面から見ると、強い光を浴びている時になんとなく見えるかな、という感じです。

また、縁の方にクラックがあり、光を浴びるとインクルージョンと一緒に輝きます。

一般的には、こうしたクラックやインクルージョンは価格を下げる要因となりますが、きれいだなあ、とつい見入ってしまいます。
