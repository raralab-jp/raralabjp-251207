新しいアプローチを試す

ハンドピースのバランス調整（Balancing）が、少し煮詰まってきた感じがしました。
そこで、別の方法がないか探したら、Justin K. Primの新しい投稿を見つけました。ステップカットの方法を使い、バランスがうまく取れているかを確認する、という内容でした。
さっそく、この方法を試してみることにしました。

ステップカットをスピネルで試す

まず、スピネルを使ってステップカットを試しました。最初のカットは少しずれていたので、2つ目でさらに調整を行いました。

調整のために、ハンドピースの脚の部分にメモリを書きました。メモリが細かすぎると、調整ができているのかわからなくなって、混乱してしまいました。メモリの細かさは、写真くらいのざっくりしたものでよさそうです。

調整時にはメモを取ることが大事です！どのメモリの位置で調整したか、どちらの方向にずれていたかを記録しておくと、混乱しなくなるし、後から見返せて便利です。

いよいよピクセルカット

ステップカットがうまくできたので、いよいよピクセルカットに戻ります。今回のピクセルカットのファセットダイアグラムはMarco VoltoliniのEasy opp squareです。

まず、#600のダイヤモンドパウダーでカットしてみましたが、特に問題はありませんでした。次に、ファインカット（Fine-cut）とプレポリッシュ（Pre-polish）のためにラップを変えて、まず#3000のダイヤモンドで磨きました。
すると、クラウンのテーブル（D）と両隣の18.10度（C）のファセットがわずかに斜めになっていることに気づきました。

スピネルのステップカットではわずかなズレだと思っていましたが、石が大きく、さらに180度回転させるため、ズレが目立ちました。そこで、さらにハンドピースを調整しました。

最終的には、この石のサイズ（だいたい2cm x 2cm）ではズレがほとんど目立たなくなりました。

次はラップとポリッシュ！

今回の調整では、ステップカットを利用することで、ハンドピースのバランスを調整する方法を試しました。
まずステップカットで調整し、ピクセルカットで細かく調整する方法が、現時点でのベストのやり方です。

脚のメモリの使い方や調整時の記録など、普段の研磨に役立つポイントも得られました。
メモリの調整は、あまり細かくしすぎないこと！チーターのメモリも、調整を細かくしすぎて混乱することがありました。もっと大きく動かしたら、違いがわかりやすく、調整しやすくなりました。

メモの重要性については、いろいろなところで目にしていましたが、今回の調整でとても助けられました。

次の記事では、ラップと手の動かし方についてまとめます。腕が痛くならないハンドピースの動かし方と、柔らかい石や大きなファセットでも速くきれいに磨くためのテクニックを探求していきます。
