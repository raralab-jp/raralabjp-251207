ダークなバイカラーのケニア産サファイア。
キラキラと瞬くインクルージョンの星屑も見ることができます。

茶色のインクルージョンのあるダークなケニア産のサファイアを、イタリアの研磨師Ramon Tesoroにカットしてもらいました。

この石の写真撮影も、特徴を掴みきれていない気がして、何度もやり直しました。
ある時ふと、ルースを画用紙に直に置き、石と同じ高さまでカメラを下げて、それから少しだけ上にセットしてみました。
そうしたら、星屑のように瞬くインクルージョンが現れました！

原石で見ると、このインクルージョンは茶色の帯のようになっています。
Ramonが茶色のインクルージョンを、キラキラと煌めくようにカットしてくれていました。

インクルージョンの分析

「このインクルージョンが何か、調べることはできますか？」
と日独宝石研究所に問い合わせたところ、

「インクルージョンが露出していれば、わかる可能性がある」
とのことでした。

このとき仕入れたサファイアの原石には、同じようなインクルージョンを含むものがけっこうあります。
機会を見つけて、インクルージョンが露出するようにカットして、分析してもらおうと思います。
