3. スラッグ（slug）仕様

● 用途
	•	/gallery/{slug}/index.html という個別ページの URL になる
	•	画像ファイルの prefix としても使う
	•	-cover.jpg が“カバー画像（正方形サムネ）”として使われる

例：

montana-sapphire-0512ct-square-step-barion

● 画像との対応

assets/images/thumb/{slug}-cover.jpg
assets/images/4k/{slug}-cover.jpg

※ Nikon のアンダースコア（ _ ）は自動対応済み。

⸻

4. 画像の扱いと命名

● 1石につき複数画像に対応

同じプレフィックスの画像はすべてサブ画像として検出される：

assets/images/thumb/{slug}-cover.jpg    ← 表示されるメイン画像
assets/images/thumb/{slug}-sub1.jpg     ← 以下、全部自動検出
assets/images/thumb/{slug}-DSC_4975.jpg
assets/images/thumb/{slug}-edited.jpg

4K 版も同じ。

● ギャラリー一覧

常に cover 画像を使う
（cover がなければ最初の画像を代用）

## ■ 1. プレート構造の正式仕様（3ブロック構造）

個別ページのプレートは **必ず以下の3ブロック構成で自動生成する**：

### ［A：日本語の商品名ブロック］

* フォーマット（例）

  ```
  モンタナサファイア 0.20ct “Simple Hexagon”
  ```
* 日本語のみ。
* 商品ページのタイトルと同等の情報。

---

### ［B：英語の商品情報ブロック］

* フォーマット（例）

  ```
  Montana Sapphire 0.20ct
  Design: “Simple Hexagon”
  ```
* **Design は必ず “Design:” ラベルつき（コロン含む）**
* Carat は「商品名の中身」を再構成するため、build.pyで自動生成する
* Weight / Carat / Design の3要素で構成される

---

### ［C：クレジット＋産地ブロック］

* フォーマット（例）

  ```
  Faceted by Rara Lab
  Origin: Montana, USA
  ```
* **Faceted by … はラベルにしない（自然文）**
* Origin は必ずラベル形式（Origin:）

---

### ■ 出力順序（改行含む・固定）

```
A
（空行）
B
（空行）
C

（空行）
［CTA］
```

CTA：

```
ご購入はこちら →
```

---

## ■ 2. CSS / 表示に関する仕様

### ● 行間（line-height）

* A / B / C 各ブロック内は現行の line-height を踏襲
* ブロック間は **1行分の margin-bottom: 24px** を推奨
  （site.css 側で `.plate p + p { margin-top: 4px }` などで細かく調整）

### ● プレート幅

* PC：**ヒーロー画像と同じ “中央寄せ 720px レイアウト” 内に置く**
* スマホ：横幅いっぱいでOK（現状の仕様で問題なし）

---

# ━━━━━━━━━━━━━━━━━━━

# 【追加仕様：サムネイル表示】

# ━━━━━━━━━━━━━━━━━━━

### ● サムネイルは端末の横幅に左右されず

**“ヒーロー画像と同じ幅の中央レイアウト内に収める”**

理由：

* 機種依存のスカスカ余白を防ぎ、統一感が出る
* 端末幅が異なっても並びの見え方が安定する

### ● 実装方法（CSS）

```
.detail .thumbs {
  max-width: 720px;       /* heroと同じ */
  margin: 0 auto;
}
```
