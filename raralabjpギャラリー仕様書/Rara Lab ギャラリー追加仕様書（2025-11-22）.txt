# 1. 一覧ページ（gallery/index.html）追加仕様

## 1-1. カラム左右の余白（左右ガター）

**スマホ・PC 共通で左右 30px を採用。**

```css
.rl-grid{
  padding-left: 30px;
  padding-right: 30px;
}
```

目的
・ギチギチした印象を避ける
・ブランドの「間」の感覚を強調
・端末間での印象差を最小化（25px → 30px で安定）

## 1-2. カード間の上下余白

**一覧カード同士の縦余白：16px → 20px**

```css
.rl-item{
  margin-bottom: 20px;
}
```

目的：スーパー棚のような詰まり感を解消し、高級感を出すため。

## 1-3. タイトル（日本語キャプション）の調整

**行間・行数・フォントサイズの最終仕様**

```css
.rl-caption{
  margin-top: 6px;
}

.rl-title{
  font-size: 0.95rem;
  line-height: 1.45;
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

@media(max-width:640px){
  .rl-title{
    font-size: 0.85rem;
    -webkit-line-clamp: 3;
  }
}
```

仕様ポイント
・PC/タブレットは2行固定
・スマホは3行
・行間を 1.45 に統一（読みやすさと省スペースのバランス）

# 3. 個別ページ（detail/index.html）追加仕様

## 3-1. 共通角丸

一覧と個別ページで角丸表現を揃える。

**角丸：全て 12px に統一**

```css
.hero img,
.thumb img,
.lb-img{
  border-radius: 12px;
}
```

目的：
・写真系サイトの統一感
・端末間で違和感が出ない最小限の丸み
・一覧と個別で「別デザイン」になって見えないようにする

## 3-2. ライトボックスの UI 角丸

Lightbox のメイン画像（.lb-img）も **12px** に統一。

※既存仕様からの追加確定項目
（最終的な UI が整ってから微調整を入れる可能性あり）
