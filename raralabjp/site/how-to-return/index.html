返品について

awai facetsでは、商品到着後に実物をご確認いただき、イメージと異なる場合にも、 以下の条件を満たす商品について返品を承ります。

お客様都合による返品

  • 商品到着後7日以内に、support@awaifacets.comまでメールでご連絡ください。
  • 未使用・未加工の商品に限ります。
  • 返送料はお客様のご負担となります。
  • 追跡可能な配送方法を利用し、元払いでご返送ください。
  • 返送先住所は、返品受付後にメールで個別にご案内します。
  • 事前のご連絡なく返送された商品は、お受け取りできない場合があります。

誤配送・到着時の破損など

ご注文と異なる商品が届いた場合、商品が到着時に破損していた場合、 その他当店の責任による返品の場合は、返送料を当店が負担します。

商品到着後7日以内にsupport@awaifacets.comまでご連絡ください。 返送方法を個別にご案内します。

返品をお受けできない場合

  • 商品到着後7日以内にご連絡がなかった場合
  • 使用または加工された商品
  • お客様のもとで傷、破損または著しい汚れが生じた商品

ケース、ソーティングカード、その他商品に付属していたものは、すべて一緒にご返送ください。 付属品に不足がある場合は、商品の状態と不足内容を確認したうえで個別に対応します。

返金について

返品された商品と付属品の到着および状態を確認後、 原則としてご注文時に利用された決済方法を通じて商品代金を返金します。

返金が利用明細や残高へ反映される時期は、決済方法、カード会社または金融機関によって異なります。

お客様都合による返品の場合、返送にかかった費用は返金対象となりません。

返品の手順

  1. 商品到着後7日以内にsupport@awaifacets.comへメールをお送りください。
  2. メールに注文番号、商品名をご記載ください。差し支えなければ、返品理由もお知らせください。
  3. 当店から返品受付と返送先住所をご案内します。
  4. 商品と付属品を、追跡可能な配送方法で元払いにてご返送ください。
  5. 商品到着後、状態を確認して返金処理を行います。
